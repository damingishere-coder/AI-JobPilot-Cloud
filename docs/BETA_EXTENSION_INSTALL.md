# Chrome 插件手动安装说明（小范围测试）

测试包文件名形如 `AI-JobPilot-Cloud-v1.6.0-beta-chrome-extension.zip`，必须同时收到 `SHA256SUMS.txt`。只从项目负责人提供的受控渠道获取，不从网盘公开链接或陌生人处下载。

项目负责人从已合并的精确提交执行 `.\scripts\package_beta_extension.ps1` 生成 ZIP 和 SHA-256；脚本会排除测试代码和本期未启用的智联脚本。

## 安装

1. 先用系统工具计算 ZIP 的 SHA-256，与 `SHA256SUMS.txt` 完整比对；不一致立即停止。
2. 把 ZIP 解压到一个固定目录，后续不要移动或删除。
3. 打开 Chrome，进入 `chrome://extensions`。
4. 打开右上角“开发者模式”，点击“加载已解压的扩展程序”，选择解压目录。
5. 确认扩展 ID 必须是 `ompipmnadogogfbebnmjgbbcadildpbc`，版本必须是 `1.6.0`；任一不一致立即停止并联系负责人。
6. 打开 `https://toudiniuma.cn` 的“浏览器插件”页面生成一次性绑定码，在插件弹窗中选择正式地址并完成绑定。

插件首期只需要访问 `toudiniuma.cn` 与 BOSS 直聘页面。它不会读取或上传招聘平台密码、Cookie、验证码、LocalStorage 或浏览器 Profile；验证码、滑块和风控必须由本人处理。

## 更新与卸载

- 更新：保存未完成状态，解压新版本到新固定目录，在扩展页删除旧版本后加载新目录，再核对固定 ID 和版本并重新绑定。
- 注销设备：先在网站“浏览器插件”页面撤销设备，再在 Chrome 扩展页移除插件。
- 不要把插件目录、绑定码或截图公开发送给无关人员。

真实投递开关默认关闭。看到“执行已关闭”属于正常保护状态；项目负责人完成正式域名模拟验收并明确通知前，不要尝试绕过。
